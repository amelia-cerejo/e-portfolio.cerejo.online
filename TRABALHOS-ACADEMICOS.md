# Trabalhos académicos

A pasta `trabalhos-academicos/` contém a fonte das páginas independentes e os dois PDFs públicos.

O fluxo de publicação de `amelia-cerejo/cerejo.online` copia o conteúdo desta pasta para a raiz do site principal. Os endereços públicos continuam a ser:

- https://cerejo.online/trabalhos-academicos.html
- https://cerejo.online/trabalho-monografia.html
- https://cerejo.online/trabalho-dissertacao.html
- https://cerejo.online/documentos/trabalhos-academicos/monografia.pdf
- https://cerejo.online/documentos/trabalhos-academicos/dissertacao.pdf

As páginas individuais aceitam `?embed=1` para incorporação sem cabeçalho nem rodapé.

Publicar primeiro as alterações deste repositório e só depois as do site principal. Em futuras atualizações dos trabalhos, executar também o workflow do site principal (Actions > Publicar site no GitHub Pages > Run workflow).

Os PDFs mantêm os nomes públicos para preservar as ligações do Europass.
